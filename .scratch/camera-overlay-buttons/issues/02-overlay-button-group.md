# 02: 相机预览右上角悬浮按钮组

**What to build:** 用户进入扫描页后，在相机实时画面的右上角看到 Torch、Camera、Cancel 三个紧凑按钮，水平排成一行并右对齐，背后垫一层深色半透明底板；文案与配色沿用底部命令栏。点击三者分别开关闪光灯、切换前后摄像头、关闭扫描页回到主页，效果与底部命令栏完全一致。底部命令栏原样保留，两组入口可互相替代。该按钮组只在 Android 上出现（该平台注册了原生相机宿主），桌面端维持只有命令栏的现状且不报错。

**Blocked by:** 01（清理 SPIKE 脚手架）

**Status:** ready-for-agent

- [ ] 进入扫描页，右上角出现三个按钮，水平一行、右对齐，尺寸明显小于命令栏按钮
- [ ] 这三个按钮显示在相机实时画面**之上**（不是画面旁边或另占一行），且画面中心取景区保持无遮挡
- [ ] 在明亮取景场景下按钮文案与边界仍清晰可辨（半透明底板生效），底板只覆盖按钮背后一条而非横跨整个画面宽度
- [ ] 点悬浮 Torch：闪光灯开；再点：关。与命令栏 Torch 行为一致
- [ ] 点悬浮 Camera：前后摄像头切换可见。与命令栏 Camera 行为一致
- [ ] 点悬浮 Cancel：扫描页关闭回到主页。与命令栏 Cancel 行为一致
- [ ] 底部命令栏的三个按钮仍然存在且可用
- [ ] 退出扫描页再进入，右上角仍只有一组按钮（幂等），相机预览仍为实时画面
- [ ] 扫码成功进入结果页时悬浮按钮不干扰结果内容；点 "Scan Again" 返回取景后按钮重新可见
- [ ] 桌面端启动无异常（不出现悬浮按钮，不崩溃）
- [ ] Android 模拟器上的验证步骤与结果追加记录到 `docs/maui-overlay-verification.md`
