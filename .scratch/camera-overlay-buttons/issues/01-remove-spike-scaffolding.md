# 01: 清理相机叠加的 SPIKE 脚手架

**What to build:** 进入扫描页仍是正常的实时相机预览，但界面上不再出现用于验证叠加机制的品红探针按钮，运行也不再输出探针诊断信息；相机内容的构建路径以它的真实职责命名，不再带 SPIKE 字样。这是一次不改行为的清理，为随后加入真实的悬浮按钮腾出干净的落点。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 进入扫描页，相机预览仍正常实时显示
- [ ] 品红探针按钮从界面上完全消失（包括其"点击切换颜色"与"弹提示"的测试行为）
- [ ] 探针专用的诊断脚手架（视图树 dump、属性读取、对象描述等帮助方法）及其全部调用点已删除，不再有任何探针相关的运行时输出
- [ ] 相机内容的构建方法以真实职责命名，代码中不再残留 SPIKE 字样的命名
- [ ] 重复进入 / 退出扫描页仍复用同一个相机会话（幂等），预览不出现永久空白
- [ ] Android 与 Desktop 两个入口均可构建通过
